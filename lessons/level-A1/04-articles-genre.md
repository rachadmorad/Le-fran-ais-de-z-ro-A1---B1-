# Leçon 4 — Les articles et le genre (un / une / le / la / les)

**Niveau :** A1 · **Durée :** ~20 min · **Prérequis :** Leçons 1–3

---

## 🎯 Ce que tu vas apprendre
- En français, chaque nom a un genre : masculin ou féminin.
- Articles indéfinis : *un* (m.), *une* (f.), *des* (pluriel).
- Articles définis : *le* (m.), *la* (f.), *l'* (devant une voyelle),
  *les* (pluriel).

---

## 📖 La règle (simplement)

Chaque nom français est **soit masculin, soit féminin**. Il n'y a pas de
logique — il faut surtout mémoriser. Mais il existe des régularités.

**Indéfini = « un / une / des »**
- *un* + masculin singulier → *un livre*
- *une* + féminin singulier → *une table*
- *des* + pluriel → *des livres*

**Défini = « le / la / l' / les »**
- *le* + masculin → *le livre*
- *la* + féminin → *la table*
- *l'* + devant voyelle ou h muet → *l'école, l'ami*
- *les* + pluriel → *les livres*

---

## 🔑 Terminaisons utiles (astuce)

Si un nom se termine par **-tion, -té, -ure, -ette, -ance, -ence** → il
est **généralement féminin** :
- *la nation, la beauté, la culture, la fille, la chance*

La plupart des autres terminaisons → **généralement masculin**.

> 🔑 **Darija :** المذكر والمؤنث فالحروف — خاصك تحفظهم. بلا ما تفكر
> بزاف، غير تعوّد.

## 💬 Phrases modèles

1. *C'est un livre.*
2. *C'est une table.*
3. *Voici l'école.*
4. *J'ai un stylo et une calculatrice.*
5. *Les amis sont ici.*

## ✏️ Mini-exercice

Mets le bon article (*un / une / le / la / l' / les*) :

1. ______ école (école)
2. ______ livre (livre)
3. ______ table (table)
4. ______ amie (amie)
5. ______ stylos (pluriel)

**Réponses :** 1. l' — 2. un (ou le) — 3. une (ou la) — 4. une (ou l') —
5. les
