# Le français de zéro (A1 → B1)

Un dépôt d'apprentissage du français, structuré et autonome, conçu pour
une élève marocaine en 1ère année du baccalauréat, **sciences
expérimentales**, qui commence de zéro (A1) et progresse étape par étape
vers un niveau intermédiaire solide (B1).

Le vocabulaire, les dialogues et les textes tournent autour de thèmes
qu'une lycéenne marocaine vit vraiment : les matières scolaires (avec un
fil léger de maths / physique-chimie / SVT), la routine quotidienne, la
famille, les amis, les loisirs, la nourriture, les courses, les sorties,
décrire les personnes et les lieux, les projets d'avenir, les opinions.

**Pas d'informatique, pas de cybersécurité, pas de thèmes professionnels
adultes, pas de contenu enfantin.**

## Comment l'utiliser (boucle hebdomadaire suggérée)

1. Lis **une leçon** dans `lessons/level-A1/`.
2. Fais le mini-exercice à la fin de la leçon.
3. Ajoute les nouveaux mots dans Anki / Quizlet (importe une seule fois
   `flashcards/level-A1.tsv`, ensuite ajoute juste les nouveaux).
4. Une à deux fois par semaine, fais quelque chose de `practice/level-A1/`
   (une lecture, une tâche d'écriture, un jeu de rôle).
5. Quand les 15 leçons sont finies, fais le **quiz A1**
   (`practice/level-A1/quiz-A1.md`) et vérifie la **checklist « prête
   pour A2 »**.

Rien n'est chronométré. Va à ton rythme. Quand A1 devient confortable, le
dossier A2 sera construit.

---

## Politique linguistique du dépôt

- **Français** = langue cible **et** langue des explications, consignes
  et traductions.
- **Darija (en alphabet arabe)** = apparaît **seulement** comme glose
  courte pour le vocabulaire clé et les points de grammaire délicats.
- **Pas d'anglais** dans le contenu.
